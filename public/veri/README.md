# Usûl güncelleme uç noktası

Android uygulaması önce aşağıdaki özel alan adını denetler:

`https://usul.sazusoz.com/veri/manifest.json`

GitHub Pages ve GitHub ham dosya adresi yedek uç noktalar olarak kullanılır.
Katalog URL'si manifeste göre bağıl tutulur; böylece aynı dosyalar GitHub,
GitHub Pages ve özel alan adında değişmeden çalışır.
