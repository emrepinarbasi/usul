# Usûl güncelleme uç noktası

Android uygulaması önce aşağıdaki özel alan adını denetler:

`https://usul.sazusoz.com/veri/manifest.json`

Alan adı hazırlanıncaya kadar GitHub ham dosya adresi yedek uç nokta olarak
kullanılır. Katalog URL'si manifeste göre bağıl tutulur; böylece aynı dosyalar
GitHub, GitHub Pages ve özel alan adında değişmeden çalışır.
